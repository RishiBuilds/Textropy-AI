**Textropy AI** is a production-grade OCR platform that unifies a **Chrome Extension**, **Streamlit Dashboard**, and **FastAPI Backend** into one seamless AI-powered pipeline — turning messy images and PDFs into clean, structured text, LaTeX-ready math, and usable data.
